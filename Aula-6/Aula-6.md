# A T I V I D A D E

## Problema: Organização de deveres

### 1. Empatia

**Como podemos resolver esse problema e ser mais organizados com nossos deveres?**

### 2. Definição

A falta de organização pode causar atrasos, deveres que acabam sendo esquecidos e dificuldade para acompanhar o que ainda precisa ser feito.

### 3. Ideação

1. Criar um dashboard com todos os deveres registrados, mostrando prazo e situação de cada atividade.
2. Criar um site que envie lembretes sobre os deveres próximos da data de entrega.
3. Criar um calendário onde seja possível visualizar os deveres organizados por dia e matéria.

### 4. Escolha

**Ideia escolhida:** criar um dashboard com os registros dos deveres, prazos e lembretes.

### 5. Histórias de usuário

**História 1.** Como estudante, quero cadastrar meus deveres no sistema, para não esquecer das atividades que preciso realizar.

**História 2.** Como estudante, quero visualizar a data de entrega de cada dever, para conseguir me organizar melhor.

**História 3.** Como estudante, quero receber lembretes dos deveres próximos do prazo, para evitar atrasos nas entregas.

### 6. Critérios de aceitação

**Critério 1.** Dado que o estudante informou os dados de um dever, quando confirmar o cadastro, então o dever deverá aparecer no dashboard.

**Critério 2.** Dado que existem deveres cadastrados, quando o estudante acessar o dashboard, então deverá visualizar o nome da atividade, a matéria e a data de entrega.

**Critério 3.** Dado que um dever está próximo da data de entrega, quando chegar o período definido para o lembrete, então o sistema deverá avisar o estudante sobre a atividade pendente.
