# ATIVIDADE

## Processo 1 - Registro de pedidos (Vendedores)

**Requisito 1**
O sistema deve permitir registrar pedidos efetuados por telefone ou presencialmente, informando o canal de venda, itens e dados do cliente.
* **Fonte 1:** Entrevista com os vendedores. Fonte humana, nível operacional, classe de usuário vendedor[cite: 1, 2].
* **Fonte 2:** Bloco de notas e planilhas usadas atualmente no atendimento. Fonte não humana, categoria documentação[cite: 1, 2].

**Requisito 2**
O sistema deve validar se há stock disponível antes de confirmar o pedido.
* **Fonte 1:** Alinhamento com a gerência de vendas. Fonte humana, nível tático[cite: 1, 2].
* **Fonte 2:** Sistema comercial antigo em uso. Fonte não humana, categoria sistema legado[cite: 1, 2].

**Requisito 3**
O sistema deve gerar um comprovante do pedido para envio automático por e-mail ou WhatsApp ao cliente.
* **Fonte 1:** Análise do fluxo de pedido em plataformas do mercado. Fonte não humana, categoria concorrência[cite: 1, 2].
* **Fonte 2:** Entrevista com os vendedores. Fonte humana, nível operacional, classe de usuário vendedor[cite: 1, 2].


## Processo 2 - Gestão de produtos (Administrador)

**Requisito 1**
O sistema deve permitir cadastrar novos produtos preenchendo código, nome, preço e categoria.
* **Fonte 1:** Entrevista com o administrador do sistema. Fonte humana, nível operacional, classe de usuário administrador[cite: 1, 2].
* **Fonte 2:** Catálogo de produtos atual da empresa. Fonte não humana, categoria documentação[cite: 1, 2].

**Requisito 2**
O sistema deve permitir inativar produtos para impedir novas vendas mantendo o histórico antigo.
* **Fonte 1:** Reunião com a diretoria comercial. Fonte humana, nível estratégico[cite: 1, 2].
* **Fonte 2:** Entrevista com o administrador do sistema. Fonte humana, nível operacional, classe de usuário administrador[cite: 1, 2].

**Requisito 3**
O sistema deve calcular a carga tributária no cadastro do preço de venda do produto.
* **Fonte 1:** Regulamentação de emissão de NF-e e impostos estaduais. Fonte não humana, categoria norma[cite: 1, 2].
* **Fonte 2:** Consultoria de contabilidade externa. Fonte humana, nível externo[cite: 1, 2].

## Processo 3 - Controle de estoque (Time de estoque)

**Requisito 1**
O sistema deve dar baixa automática no stock assim que um pedido for separado e despachado.
* **Fonte 1:** Entrevista com os operadores do almoxarifado. Fonte humana, nível operacional, classe de usuário time de estoque[cite: 1, 2].
* **Fonte 2:** Manual de procedimentos de expedição interno. Fonte não humana, categoria documentação[cite: 1, 2].

**Requisito 2**
O sistema deve dar entrada no stock registando a quantidade do lote, fornecedor e número da nota fiscal.
* **Fonte 1:** Entrevista com o conferente de receção. Fonte humana, nível operacional, classe de usuário time de estoque[cite: 1, 2].
* **Fonte 2:** Notas fiscais de entrada dos fornecedores. Fonte não humana, categoria documentação[cite: 1, 2].

**Requisito 3**
O sistema deve alertar a equipa de estoque quando o saldo de um produto atingir a quantidade mínima de segurança.
* **Fonte 1:** Definição de regras com o supervisor de logística. Fonte humana, nível tático[cite: 1, 2].
* **Fonte 2:** Parâmetros do sistema antigo de inventário. Fonte não humana, categoria sistema legado[cite: 1, 2].
